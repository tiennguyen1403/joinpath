## Quyết định trong session

**User duyệt** ("approve với tất cả đề xuất", hai lần):
1. Hủy DRAFT trên UI: nút ở review của wizard. Lý do: draft bị bỏ dở chặn tạo onboarding mới cho người đó (partial unique DRAFT/ACTIVE), mà UI chưa có đường nào bỏ draft.
2. Phần API nhỏ nằm trong session web này.
3. **Lý do hủy chỉ HR thấy** (phương án A): giống khung Invitation; lý do có thể nhạy cảm. Đã đóng quyết định mở trong STATUS.
4. **Reset deadline là link trong dialog đổi hạn** (phương án A): menu giữ đúng 2 mục như canvas. Phương án B (mục thứ ba trong menu) bị loại.
5. Dialog dùng `center-morph-modal`, menu dùng `context-menu` (sửa để mở bằng click). Nút xác nhận hủy nền `destructive/10`, chữ `danger-strong`: beUI không có biến thể destructive, chữ trắng trên `#EE343B` không đạt 4.5:1, nên không thêm chỗ lệch ADR 009.
6. Icon task bị hủy màu muted. Hủy draft xong thì ở lại trang, trang hiện trạng thái Canceled.

**Tự quyết khi làm** (user đổi được):
- **Câu chữ "HR set" thay "you set"** (dialog đổi hạn, danh sách trong dialog đổi ngày, toast đổi ngày): HR khác có thể đã đặt hạn đó.
- **Bỏ `autoFocus`** vì oxlint (`jsx-a11y/no-autofocus`, `--deny-warnings`). Dialog tự đưa focus vào phần tử đầu tiên: ô lý do ở dialog hủy, ô chọn người ở Reassign, nút "Choose month" ở hai dialog có lịch.
- **Một modal cho cả 4 thao tác.** Focus trả về nút đã mở dialog (nút header hoặc ⋯), vì modal chỉ tự trả focus cho trigger của chính nó. `onOpenChange` truyền vào modal phải giữ nguyên hàm (dùng ref): modal chạy lại effect focus mỗi khi callback đổi.
- **Nút ⋯ hiện cả trên task của nhân viên mới**, menu chỉ có Change due date…. API cho đổi hạn nhưng chặn reassign task này (409).
