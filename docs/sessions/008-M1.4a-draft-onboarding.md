## Ghi chú môi trường

- **Prisma 7.10, `partialIndexes`:**
  - Dạng object của `where` không có `in`; dùng `raw(...)`.
  - Chuỗi trong `raw` phải giống hệt kết quả của `SELECT pg_get_expr(indpred, indrelid) FROM pg_index WHERE indexrelid = '<index>'::regclass`, bỏ cặp ngoặc ngoài cùng.
- **`prisma migrate dev` khi schema còn lệch DB:** lệnh áp migration đang chờ, rồi muốn tạo migration mới và hỏi tên, nên báo lỗi "non-interactive" trong Claude Code. Kiểm lại bằng `migrate status` và `migrate diff`.
- **Cột `DATE` qua adapter pg của Prisma:**
  - Khi ghi, adapter lấy ngày bằng getter UTC; khi đọc, chuỗi `YYYY-MM-DD` thành `Date` lúc 0h UTC.
  - API đổi qua lại bằng `toISOString().slice(0, 10)` và ``new Date(`${d}T00:00:00Z`)``.
- **DeprecationWarning của pg:** xuất hiện khi trong interactive transaction có select nhiều quan hệ (xem "Tự quyết"). Tìm nguồn bằng `NODE_OPTIONS=--trace-deprecation`.
- **Canvas:** đã đọc lại các màn NewOnboarding, Dashboard, OnboardingDetail, MyTasks (bản 1792039184-b843). Phần cần dùng đã chép vào mục "Cho M1.4b" và "Cho M1.6" ở trên.
- Postgres trong Docker vẫn chạy (healthy); test của api cần nó.
