## Ghi chú môi trường

- **`pnpm build` khi `pnpm dev` đang chạy:** api dev chết với lỗi MODULE_NOT_FOUND (`nest build` xóa `dist`); web dev vẫn chạy. Dừng dev trước khi build, hoặc chạy lại `pnpm dev` sau đó.
- **Dừng `pnpm dev` chạy nền** (TaskStop) trên Windows không tắt các tiến trình node của next và nest.
  - Tìm bằng `Get-CimInstance Win32_Process -Filter "Name = 'node.exe'"`, lọc command line có `joinpath` và `next`, `nest` hoặc `apps\api`.
  - Rồi `Stop-Process`.
- **Đăng nhập Playwright CLI mà không lộ mật khẩu:**
  1. Script node đọc `SEED_PASSWORD` bằng `process.loadEnvFile('apps/api/.env')`, rồi `POST /api/auth/login` thẳng vào `http://localhost:3001`, kèm header `origin: http://localhost:3000`.
  2. Ghi storage state `{ cookies: [{ name: '__Host-sid', value, domain: 'localhost', path: '/', expires: -1, httpOnly: true, secure: true, sameSite: 'Lax' }], origins: [] }` vào scratchpad.
