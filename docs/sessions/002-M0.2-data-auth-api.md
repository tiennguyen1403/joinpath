## Còn dở và nợ kỹ thuật

- **M0.3: rewrite của Next.js có giữ nguyên `Origin` không?**
  - Nếu proxy đổi header này, mọi request ghi từ trình duyệt sẽ bị 403.
  - Nếu proxy bỏ header, Origin check sẽ không bao giờ chạy mà không báo gì.
  - Kiểm tra bằng login thật qua `:3000`, và gửi thử một `Origin` lạ qua `:3000` phải nhận 403.
- **M0.4 (đã ghi vào dòng M0.4 trong STATUS):**
  - **`trust proxy` cho đúng số hop** (Next rewrite + proxy của host). Thiếu thì throttle login coi mọi người là một IP, cả hệ thống chỉ được 10 lần/phút (PLAN §6.6, ADR 007).
  - **Log kèm request id** (user đã quyết định để M0.4).
  - **CI:**
    - Cần env `DATABASE_URL` và `APP_ORIGIN`.
    - Thứ tự chạy: `pnpm install --frozen-lockfile` → `pnpm -r build` (bước này sinh client Prisma) → `pnpm --filter @joinpath/api exec prisma migrate deploy` → test, lint, typecheck, `format:check`.
  - **Seed trên prod:** `pnpm build`, rồi chạy `pnpm db:seed` với `SEED_PASSWORD` là một secret.
- **Swagger `/api/docs` (PLAN §8) chưa thuộc session nào.**
  - CSP mặc định của `helmet` sẽ chặn script inline của Swagger UI, nên phải chỉnh khi thêm Swagger.
  - Đã đưa vào "Quyết định còn mở".
- **Email phân biệt hoa thường ở DB:** unique của `users.email` phân biệt hoa thường; login thì đã lowercase input. M1.3 (tạo nhân viên) phải lowercase lúc ghi. Đã ghi vào dòng M1.3.
- **Dọn session hết hạn:** để cron tick ở M3.2 (PLAN §6.5).
- **`details` của `VALIDATION_FAILED`:** đang trả nguyên issue của Zod, có cả regex email. Chuẩn hóa ở M1, khi validate template cần `details` theo task key.
- **Chưa kiểm tra lỗi body JSON hỏng:** lỗi của body-parser có thể không đi qua filter, nên có thể không đúng dạng `{ code, message }`. Rà ở M5.2 (trạng thái lỗi).
- **Chưa gọi `app.enableShutdownHooks()`:** khi process tắt thì pool cũng đóng. Thêm nếu host cần graceful shutdown.

## Ghi chú môi trường

- **Prisma 7.10:**
  - **Version:** pin exact. Tag `latest` trên npm là `8.0.0-rc.22`, và CLI hiện banner mời update; bỏ qua banner này.
  - **`.env`:** Prisma không tự đọc. `prisma.config.ts` gọi `process.loadEnvFile()` nếu có file.
  - **Datasource `url`:** chỉ khai báo trong `prisma.config.ts`; ghi `url` trong `schema.prisma` là lỗi validate ở 7.10. Không dùng `env()` trong config, vì nó throw khi biến chưa đặt.
  - **`migrate dev`:** không tự chạy `generate` hay seed. Phải truyền `--name` khi chạy non-interactive.
  - **`migrate reset`:** bị Prisma chặn khi chạy từ AI agent. Muốn chạy thì phải hỏi user; chỉ khi user đồng ý mới được đặt env `PRISMA_USER_CONSENT_FOR_DANGEROUS_AI_ACTION` (giá trị là nguyên văn câu đồng ý của user).
  - **Docs:** các trang không ghi version trên prisma.io đã mô tả Prisma 8 (vd guide NestJS, trang transactions). Đọc các trang `/v7/`.
- **pnpm `allowBuilds`:**
  - `@prisma/engines: true`: postinstall tải schema engine về.
  - `prisma: false`: preinstall chỉ kiểm tra version Node.
- **`crypto.argon2`** (Node 24.21): khoảng 50 ms cho mỗi hash với m=19456, t=2, p=1.
- **psql 16 trên Windows:** option phải đứng trước connection string (`psql -At -c "…" postgresql://…`); đặt sau sẽ bị bỏ qua.
- **Dừng API chạy nền:** tìm process giữ port 3001, cùng các process `node` có `nest start` trong command line (Nest CLI sinh process con), rồi `Stop-Process`. Task nền bị kill sẽ báo exit code 127; điều đó bình thường.
